Welcome to **SquatClient**, a graphical client for MUDs, MUSHes and other MU* games. It remembers your worlds, keeps full-colour scrollback, lets you automate things with a TinyFugue-style scripting language or Lua, and can keep your connections alive while the app is closed.

This help is built into the app. It works offline and everything in it is searchable.

## Where to start

- New here? Read [Getting started](help:getting-started).
- Want to connect to a game? See [Connecting and worlds](help:connecting).
- Want your connections to survive closing the app? See [Squatter](help:squatter).
- Looking for a key? See [Keyboard shortcuts](help:keys).
- Something not working? See [Troubleshooting](help:troubleshooting).
- Want to automate things with triggers and macros? Start with [the scripting language](help:scripting), then [Lua scripting](help:lua).
- Unsure what a word means? See the [Glossary](help:glossary).

## Using this help

| To do this             | Do this                                                                                                                     |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Open help              | type `/help`, press F1 (Cmd-? on macOS), choose Help in the menu, or click the **?** button                                 |
| Open a topic           | `/help def`, `/help keys`, `/help squatter` (a leading `/` is fine: `/help /def`)                                           |
| Search                 | type in the search box, or `/help some words`                                                                               |
| Move around            | click the topic tree, follow links, or press Alt-Left and Alt-Right for back and forward                                    |
| Jump to the search box | press `/`                                                                                                                   |
| Close                  | press Escape                                                                                                                |
| Try an example         | every code block has **Copy** and **Insert into input** buttons; Insert puts the text on your input line without sending it |

SquatClient's scripting language is modelled on [TinyFugue](help:about#tinyfugue), written by Ken Keys. Thank you, Ken.
