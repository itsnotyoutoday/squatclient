Recent additions you can see and use.

## TinyFugue

- **TinyFugue as a squatter.** Pair with a TinyFugue running on a server, see all its connections and choose who types and who runs triggers. See [TinyFugue as a squatter](help:squatter/tinyfugue).

## Command window

- **Resizable command window.** Drag the bar above the input to make it taller, up to about 70% of the window. Double-click the bar to reset it. See [Using the client](help:using#resizing-the-command-window).
- **Multi-line mode.** A larger editor for writing several lines at once. Press the **Multi-line** button or Cmd/Ctrl-Shift-E. See [Using the client](help:using#multi-line-mode).
- **Command history browser.** Press Ctrl-R (or Cmd-Shift-H) to search everything you have sent to a world, with regular expression and case options. See [Using the client](help:using#history-browser).
- **Command history size.** Choose how many entries each world keeps in [Settings](help:settings).

## Privacy

- **Password protection.** Login and password lines are masked on screen and never saved in history. Use `/secret text` to send anything else privately. See [Passwords](help:using#passwords).

## Colours

- **Terminal-matched colours.** The default dark theme uses a classic terminal palette so games that send the 16 basic colours look like they do in other clients. See [Colours](help:using#colours).
- **`/colortest`.** Prints every colour mode so you can compare SquatClient with another program. See [Troubleshooting](help:troubleshooting#colours-look-different).

## Writing softcode

- **Code editor with MUSH syntax highlighting.** The code editor colours MUSH functions, brackets and comments so softcode is easier to read.
