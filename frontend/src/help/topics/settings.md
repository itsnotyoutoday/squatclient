Open settings with Ctrl-, (Cmd-, on macOS), the menu (Session, Settings) or the gear button. Changes apply immediately.

| Setting                                        | Meaning                                                                                                                                                                                                                                    | Default                                             |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------- |
| Theme                                          | Dark, Light, High contrast, or an imported theme                                                                                                                                                                                           | Dark                                                |
| Import theme (JSON)                            | add your own theme from JSON text                                                                                                                                                                                                          | none                                                |
| Font family                                    | font stack for the output and input                                                                                                                                                                                                        | JetBrains Mono, SF Mono, Menlo, Consolas, monospace |
| Font size (px)                                 | size of text in the output                                                                                                                                                                                                                 | 14                                                  |
| Scrollback lines in memory                     | how many lines per tab are kept in memory; older history is fetched on demand                                                                                                                                                              | 20000                                               |
| Minimum contrast                               | 0 turns it off; 4.5 meets WCAG AA; colours are adjusted to reach it                                                                                                                                                                        | 0                                                   |
| Default encoding                               | UTF-8 or Latin-1 for new connections; a world can override it                                                                                                                                                                              | UTF-8                                               |
| Show timestamps                                | prefix each line with its time                                                                                                                                                                                                             | off                                                 |
| Bold text uses bright colours                  | bold basic colours become bright colours                                                                                                                                                                                                   | off                                                 |
| Make bare URLs clickable                       | turn `http://` and `https://` text into links                                                                                                                                                                                              | on                                                  |
| Pause output when scrolled up                  | freeze live output while you read older text                                                                                                                                                                                               | on                                                  |
| Desktop notifications                          | notify about activity in background tabs                                                                                                                                                                                                   | on                                                  |
| Screen-reader mode                             | announce new lines to assistive technology                                                                                                                                                                                                 | off                                                 |
| Command history size                           | entries kept per world, 100 to 1,000,000 (values outside are clamped; 0 is not allowed). Stored on disk for each world and shared by all its sessions; older entries are dropped first. Lowering it trims on the next write and at startup | 20000                                               |
| History of the current world                   | shows how many entries the foreground world has stored, with a **Clear history** button (asks to confirm)                                                                                                                                  | -                                                   |
| Delay between block lines                      | multi-line mode: milliseconds between the lines of a sent block (0 sends them at once); 0 to 10000                                                                                                                                         | 0                                                   |
| Reconnect to squatters automatically           | bring a lost link to a squatter back by itself after sleep or a network drop; your games stay connected on the squatter meanwhile                                                                                                          | on                                                  |
| Editor: join indented lines                    | a line starting with whitespace continues the previous line (leading whitespace removed, nothing inserted)                                                                                                                                 | on                                                  |
| Editor: drop blank and @@ comment lines        | blank lines and lines holding only an `@@` comment are not sent                                                                                                                                                                            | on                                                  |
| Editor: ask before sending unbalanced brackets | before sending from the editor, and in the [upload](help:using#uploading-a-file) dialog, check `( ) [ ] { }` and ask (_Fix first_ or _Send anyway_) when they do not balance                                                               | on                                                  |

The heights of the command window and the editor are set by dragging (see [Using the client](help:using#resizing-the-command-window)); they are saved as settings too.

The scrollback size is applied when the app starts. Truecolour is always on.

Other places that hold settings: worlds ([Connecting and worlds](help:connecting)), squatters ([Squatter](help:squatter)) and scripts ([the scripting language](help:scripting)).
